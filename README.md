# OPAirPods

OPAirPods 是一个 Android / LSPosed 模块，将 AirPods 的部分高级功能接入 ColorOS 原生耳机设置页面。项目使用宿主的设置界面和对话框，让耳机控制融入系统原有体验。

## 功能

- 在原生页面调整麦克风、按压与长按、音量滑动、单耳降噪、个性化音量和自适应强度等设置。
- 首页选中自适应模式后，可左右拖动自适应按钮调节强度，松手后发送设置；向左减弱，向右增强。
- 调整提示声音量、通话按键组合、长按循环模式和优化电池充电；收到耳机有效回报后开放操作，并显示设置确认状态。
- 使用三段硬件均衡器；为左右耳柄的单按、双按、三按、长按分配动作，并呼起系统配置的默认语音助手。
- 头部操控（实验性）：点头接听、摇头拒接，可交换动作，提供最长 30 秒的“试一试”。默认关闭，耳机型号与固件兼容性及实际通话效果待实机验证。
- 头部运动方向提示音：左右转动使用对应声道的轻响，上下运动使用居中的不同音高；来电反馈跟随耳机通话输出；体验完整识别或系统确认通话操作成功后，再播放清脆确认音。
- 在「耳机功能 → 聆听体验 → 个性化空间音频」选择「头部追踪」。戴好耳机，在平板上播放支持系统空间化的内容，面向前方点「以当前方向回正」。默认追踪左右转头；在播放时点「校准头部方向」，按提示完成后也会追踪俯仰和侧倾。每副耳机分别保存模式和校准，离开设置页后继续生效。
- 配置通透模式定制、响音降低和听力辅助相关参数。
- 查看多设备连接与音频来源，手动或在手机播放时切换音频。
- 手机暂停播放时保留当前设备；连接初始化或播放接管取消不会主动切到空闲设备。
- 显示多设备切换提示，并提供返回手机的操作。
- 查看连接与设置状态，恢复耳机控制连接。
- 在原生电量区域显示充电盒电量与充电状态；盒子暂时不回报时，最多保留最近已知电量 15 分钟。
